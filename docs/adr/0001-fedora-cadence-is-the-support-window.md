# Fedora cadence is the support window

FWOS tracks Fedora: ship host image N, keep N-1 pullable until Fedora EOLs it. There is no FWOS LTS. Atomic `bootc upgrade` and rollback make a six-month rebase survivable; they do not make a five-year freeze. A longer window would require a different base (for example CentOS Stream), not a slogan on `fedora-bootc`.
