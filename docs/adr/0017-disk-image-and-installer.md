# qcow2 Disk image first; Anaconda ISO Installer for empty-disk VM and metal

KVM-first First install is a prebuilt qcow2 Disk image: attach and boot. Metal, and a VM with an empty disk, use one Anaconda ISO Installer that writes the same Host image, UEFI, whole-disk. We do not ship a VM-only installer, a dd-raw metal path, or PXE as v1.
